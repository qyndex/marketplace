# Marketplace

Two-sided marketplace with listings, search, messaging, and Stripe payments.

**Stack:** Nextjs | **Complexity:** enterprise
**Tags:** `marketplace`, `prisma`, `search`, `payments`, `messaging`, `nextjs`

## Quick Start

```bash
npm install
npm run dev
```

## Docker

```bash
docker compose up --build
```
